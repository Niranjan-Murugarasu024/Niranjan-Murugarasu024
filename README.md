## 01 — 🏢 Enterprise Sales Data Warehouse

### End-to-End Data Engineering Platform

An end-to-end **SQL Server Data Warehouse** integrating heterogeneous **CRM and ERP datasets** into a centralized analytical platform using **T-SQL and Medallion Architecture**.

### 🏗️ Architecture

```mermaid
flowchart LR

    CRM["📦 CRM<br/>Customer Data"]

    ERP["📦 ERP<br/>Sales & Product Data"]

    BRONZE["🥉 BRONZE<br/>Raw Data<br/>Source Preservation"]

    SILVER["🥈 SILVER<br/>Clean<br/>Standardize<br/>Validate"]

    GOLD["🥇 GOLD<br/>Business-Ready<br/>Integrated Data"]

    FACT["📊 FACT TABLES<br/>Sales<br/>Orders<br/>Transactions"]

    DIM["🧩 DIMENSIONS<br/>Customer<br/>Product<br/>Date"]

    ANALYTICS["📈 ANALYTICS<br/>Customer Behavior<br/>Product Performance"]

    REPORTING["📋 REPORTING<br/>Business Metrics<br/>Decision Support"]


    CRM --> BRONZE
    ERP --> BRONZE

    BRONZE --> SILVER
    SILVER --> GOLD

    GOLD --> FACT
    GOLD --> DIM

    FACT --> ANALYTICS
    DIM --> ANALYTICS

    FACT --> REPORTING
    DIM --> REPORTING


    classDef source fill:#EFF6FF,stroke:#2563EB,color:#111827,stroke-width:2px;
    classDef bronze fill:#FFF7ED,stroke:#F59E0B,color:#111827,stroke-width:2px;
    classDef silver fill:#F8FAFC,stroke:#64748B,color:#111827,stroke-width:2px;
    classDef gold fill:#ECFDF5,stroke:#0F766E,color:#111827,stroke-width:2px;
    classDef schema fill:#F5F3FF,stroke:#7C3AED,color:#111827,stroke-width:2px;
    classDef output fill:#F0FDF4,stroke:#16A34A,color:#111827,stroke-width:2px;

    class CRM,ERP source;
    class BRONZE bronze;
    class SILVER silver;
    class GOLD gold;
    class FACT,DIM schema;
    class ANALYTICS,REPORTING output;
```

### 🔧 Engineering Work

- 🔗 Integrated heterogeneous CRM and ERP datasets
- 🥉 Designed the **Bronze** raw-data layer
- 🥈 Implemented cleansing, standardization, normalization and validation in the **Silver** layer
- 🥇 Developed a business-ready **Gold** layer
- 🧩 Implemented fact and dimension tables
- ⭐ Designed a **Star Schema**
- 🔄 Built reusable ETL and transformation workflows
- 🔍 Added data-quality validation checks
- 📊 Developed analytical outputs covering:
  - Customer behavior
  - Product performance
  - Sales trends
- 📚 Documented data architecture, data flow, data catalog and naming conventions
- 🔐 Maintained implementation in Git for reproducibility and version control

### 🧰 Technology

`SQL Server` · `T-SQL` · `ETL` · `Data Warehousing`

`Medallion Architecture` · `Dimensional Modeling` · `Star Schema`

`Data Quality` · `Data Validation` · `Git`

### 🔄 Data Pipeline

```mermaid
flowchart LR

    A["🗂️ Government<br/>Datasets"]

    B["📐 Schema<br/>Standardization"]

    C["🔗 Entity<br/>Resolution"]

    D["🗺️ District<br/>Crosswalk"]

    E["🩹 Missing Data<br/>Handling"]

    F["✅ Validation"]

    G["🧩 Feature<br/>Construction"]

    H["📊 Analytical<br/>Dataset"]

    I["📐 Quantitative<br/>Scoring"]


    A --> B
    B --> C
    C --> D
    D --> E
    E --> F
    F --> G
    G --> H
    H --> I


    classDef process fill:#F8FAFC,stroke:#0F766E,color:#111827,stroke-width:2px;

    class A,B,C,D,E,F,G,H,I process;
```

### 🔧 Engineering Work

- 🗂️ Integrated six heterogeneous government datasets
- 🌍 Processed data across **780+ Indian districts**
- 📐 Standardized inconsistent source schemas
- 🔗 Built district entity-resolution workflows
- 🗺️ Developed a district crosswalk
- 🔄 Handled historical district changes
- 🩹 Implemented missing-data handling
- ✅ Built automated validation workflows
- 🧩 Developed feature-construction pipelines
- 📊 Created standardized analytical datasets
- 📐 Developed a **7-pillar quantitative scoring model**
- 🎯 Applied AHP, entropy-based weighting and competitive-intensity adjustment
- 🎲 Evaluated ranking robustness across **3,000 Monte Carlo weight perturbations**
